Introducing Kimi K3.1 Pro

月之暗面 10/24 發布 Kimi K3.1 Pro，是 Kimi K3 加大後訓練（強化學習）算力的版本，另有快 2–3 倍的 K3.1 Pro Highspeed。【比上一版進步在哪（官方說法）】Terminal-Bench 4.0 拿 65.7%，高於 GPT-6 Astra（58.2%）、略低於 Claude Opus 5.5（66.4%）；自家長程程式評測 Kimi Code Bench 3.0 從 K3 的 55.95% 升到 61.2%；BenchCAD（從多視角圖用 CAD 程式重建 3D）有工具時 92.7%。官方強調能用 Unity、Unreal、Godot 做完整遊戲，會寫腳本操作 Blender 與 CAD 做參數化 3D 模型，kimi.ai 同步上線可預覽、下載 3D 列印檔的 3D Make。【規格】官方貼文寫總參數 2.8T、每次啟用 104B、100 萬 token 上下文、多模態。【哪裡能用】今天起在 Kimi.ai 與手機 App、Kimi Work（3.1.0 以上）、Kimi Code（/model 切換）與 Kimi API（kimi-k3.1-pro／kimi-k3.1-pro-highspeed）；完整權重官方說 11/4 前釋出。【第三方】多家 AI 日報引用 Artificial Analysis 智慧指數，K3.1 Pro 拿 55 分排第 4，高於 Claude Fable 5.1、GPT-6 Astra 與 Gemini 4 Argon（皆 53）；這部分依轉載整理，評測數字多為官方自測，獨立實測仍少。

Donating Agent Skills to the Agentic AI Foundation

Anthropic 10/22 宣布把 Agent Skills 開放標準捐給 Agentic AI Foundation（AAIF，Linux 基金會旗下，由 Anthropic、Block、OpenAI 共同成立，MCP 也已捐在這裡）。一個 skill 就是一個含 SKILL.md 的資料夾，教 AI 代理做某件特定工作，可附腳本與參考資料。官方說 2025 年 12 月公開標準以來，ChatGPT、Cursor、GitHub Copilot、VS Code 等 70 多個平台已整合，累計發布 100 萬個 skill、安裝近 2.8 億次。這次捐出名稱與標誌、GitHub 組織與 agentskills.io 網域；不加入 AAIF 也能照用或貢獻，由 Anthropic、Google、OpenAI 等公司的工程師以個人身分維護。下一步提議版本化發布、正式提案流程與安裝 skill 的安全指引。

教學區

Learn
中階 · VRAM 官方未列 VRAM；模型檔 14B 約 32GB、1.3B 約 7GB（依原頁為準，顯存小建議先用 1.3B，只支援 480P）常青教學

Wan2.1 VACE：一個模型做影片的換背景、局部替換、動作轉移與延伸

學會下載 VACE 模型、載入 ComfyUI 官方範本，並用「略過（Bypass）」節點切換文生影片、參考圖生影片、影片轉影片等用法。

VACE：阿里通義萬相開源的影片編輯模型，同一個模型能做多種影片生成與修改Bypass（略過）：讓節點暫時不作用、資料直接穿過，用來切換範本裡的不同功能

看更多：步驟
  1. 先把 ComfyUI 更新到最新版，範本庫（Workflow Templates）裡找不到 VACE 範本通常就是版本太舊。
  2. 下載擴散模型 wan2.1_vace_14B_fp16.safetensors（約 32GB）或較輕的 wan2.1_vace_1.3B_fp16.safetensors（約 7GB），放到 ComfyUI/models/diffusion_models/。
  3. 另外下載 wan_2.1_vae.safetensors 放進 models/vae/，文字編碼器 umt5_xxl_fp8_e4m3fn_scaled.safetensors（較省顯存）或 fp16 版放進 models/text_encoders/；用過 Wan 影片範本的人這兩個應該已經有了。
  4. 開啟範本，確認 Load Diffusion Model、Load CLIP、Load VAE 三個節點各自載到上面的檔案。
  5. 依想做的事把不需要的輸入節點設成 Bypass（官方頁列有三種切換方式），例如只有文字就略過參考圖和參考影片，再按 Queue 執行；官方頁提醒文件正在改版，細節以範本內的註記為準。
教學來源：ComfyUI 官方文件：Wan2.1 VACE Video Examples ↗VACE 官方 GitHub ↗Hugging Face：Wan-AI/Wan2.1-VACE-1.3B ↗
入門 · VRAM 官方頁未列 VRAM（依原頁為準）常青教學

Flux.1 Fill dev：補畫（Inpaint）與往外延伸畫面（Outpaint）

學會用官方範本把圖片裡塗掉的區域補畫好，或把畫面往外擴，兩種用法共用同一組模型檔。

Inpaint（局部重繪）：只重畫圖片裡用遮罩塗起來的部分，其他地方不動Outpaint（外擴）：把畫面往四周延伸，讓 AI 補出原本圖外的內容

看更多：步驟
  1. 先到 Hugging Face 的 black-forest-labs/FLUX.1-Fill-dev 頁面同意使用條款，才下載得到模型。
  2. 下載 flux1-fill-dev.safetensors 放 models/diffusion_models/，clip_l 與 t5xxl_fp16 放 models/text_encoders/，ae.safetensors 放 models/vae/；用過 Flux.1 文生圖的人只缺 fill 這一個檔。
  3. 從範本庫搜尋「Flux.1 Inpaint」，確認 Load Diffusion Model、DualCLIPLoader（t5xxl＋clip_l）、Load VAE 都載對檔案。
  4. 把官方範例圖（已含透明遮罩）上傳到 Load Image；想自己畫遮罩就換沒有遮罩的原圖，在 Load Image 上開遮罩編輯器塗。
  5. 按 Queue 或 Ctrl＋Enter 執行；要外擴就改開「Flux.1 Outpaint」範本，用同一組模型。
教學來源：ComfyUI 官方文件：Flux.1 fill dev Example ↗Hugging Face：black-forest-labs/FLUX.1-Fill-dev ↗
