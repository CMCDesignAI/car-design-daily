ChatGPT now lets you lock your chats

OpenAI 10/20 宣布 ChatGPT 可以把對話上鎖，用 4 位數 PIN，或在支援的裝置上用 Face ID／Touch ID 解鎖。【怎麼運作】上鎖的對話移到獨立的「Locked Chats」區，不會出現在一般聊天紀錄、釘選和搜尋結果；和「臨時聊天」不同，上鎖的對話可以隨時回來繼續。開啟記憶功能時，Locked Chats 有自己獨立的記憶，上鎖後的新內容不會流進一般記憶。【限制】官方說上鎖不是端對端加密、也不是加密保險箱，不改變保留期限、不刪除上鎖前已記住的內容、不改變「改善模型」設定；重設 PIN 會永久刪除所有上鎖聊天與檔案；臨時、封存、群組、分享連結建立的、排程任務與會議錄音的聊天不能上鎖。【哪裡能用】Free、Go、Plus、Pro、Business、Enterprise、Edu 方案（ChatGPT for Healthcare 除外），10/20 起分批推出，可能還沒輪到你。

在 ComfyUI 用 Hunyuan3D 把一張圖變成 3D 模型（.glb）

用官方範本把產品或車子的照片轉成可在 3D 軟體打開的模型網格。

3D 網格（Mesh）：由許多小三角形拼成的立體模型表面，3D 軟體都能開.glb：一種常見的 3D 模型檔案格式，可直接拖進 Blender 或網頁檢視器

看更多：步驟
  1. 先把 ComfyUI 更新到新版，在範本庫搜尋「HY 3D 2.1」（單張圖）或「HY 3D 2.0 MV」（多視角圖）打開官方工作流程。
  2. Hunyuan3D 2.1：下載 hunyuan_3d_v2.1.safetensors（約 7.4GB）放到 ComfyUI/models/checkpoints/。
  3. 確認 Image Only Checkpoint Loader(img2vid model) 節點選到這個檔案，在 Load Image 放入一張主體清楚的圖。
  4. 按 Queue（或 Ctrl／Cmd + Enter）執行；有前、左、後、右視角圖的話改用 2.0 MV 範本，細節會更好。
  5. 生成的 .glb 會存在 ComfyUI/output/mesh/；注意 ComfyUI 原生目前只產生沒貼圖的形狀，要材質需用社群擴充。

用 FastVideo 在自己的電腦跑 MiniMax H3 加速版（FastH3）

看懂自己的顯卡能跑哪個 FastH3 版本，並用官方 Cookbook 產生的指令跑出第一支有聲短片。

uv：比 pip／conda 更快的 Python 套件與虛擬環境管理工具Recipe（食譜）：官方幫你配好的一組模型、參數與指令，照著跑就行

看更多：步驟
  1. 先對照顯存：RTX 5090（32GB）建議 FastH3 V2 NVFP4，24GB 以下用 FP8 或 Trim；Mac 走 MLX 版，目前只支援文字生影片。
  2. 下載程式：git clone https://github.com/hao-ai-lab/FastVideo.git，再 cd FastVideo。
  3. 建環境：uv venv --python 3.12 --seed 並啟用；NVIDIA 執行 UV_TORCH_BACKEND=cu130 uv pip install -e ".[fasth3]"，Mac 執行 uv pip install -e ".[mlx]" 並照 MLX 安裝指南裝 ffmpeg。
  4. 打開官方 Cookbook 的 MiniMax H3 頁，選 FastH3 8-Step V2、Trim 或新的 OmniRef（參考輸入），在產生器設定 GPU 數量和 VAE，複製產生的指令執行。
  5. 注意：參考輸入、首尾影格目前只有 CUDA 版支援；H3 授權預設排除美國地區，商用前先看授權。

入門 · VRAM 不需要（介面操作）常青教學

ComfyUI 必學快捷鍵：執行、略過節點、整理畫面，一次學會

記住十來個常用快捷鍵，操作工作流程快一倍，也知道怎麼自訂按鍵。

Bypass（略過）：讓某個節點暫時不作用、資料直接穿過去，方便比較有沒有它的差別Mute（停用）：讓節點完全不執行

看更多：步驟
  1. 執行：Ctrl + Enter 排入佇列；Ctrl + Alt + Enter 中斷目前的執行（Mac 用 Cmd）。
  2. 存讀檔：Ctrl + S 儲存工作流程、Ctrl + O 載入；Ctrl + Z／Ctrl + Y 復原與重做。
  3. 節點：Ctrl + B 略過（Bypass）、Ctrl + M 停用（Mute）、Alt + C 收合、Ctrl + G 幫選取的節點加外框分組。
  4. 畫面：按住空白鍵移動畫布、按「.」縮放到選取的節點、在空白處雙擊左鍵快速搜尋節點；F 切換專注模式。
  5. 自訂：按齒輪（或 Ctrl + ,）→ Keybinding，點指令前的編輯圖示就能改成自己習慣的按鍵。
