Meta 新一代 AI 助理，會記住你之前講過的重點、遇到卡關會自己換方法；第三方評測給 56 分，比上一代高 8 分。

Introducing Muse Wonder and Muse Wonder Full

Meta Superintelligence Labs 10/12 推出 Muse Wonder 系列：API／Muse Code 可用的 Muse Wonder，以及僅 Muse Code 訂戶可用、分數更高的 Muse Wonder Full。兩者皆標 1M 上下文，輸入含文字／圖／影片／音訊，輸出文字；強調 Active Memory（跨對話記住重點）與 Active Focus（長任務換路徑、遇阻再試、重要動作前確認）。Wonder API 定價每百萬 token 輸入 4／快取 0.20／輸出 20 美元（與 Claude Opus 5.5 同級）。官方自測表把兩款與 Fable 5.1、GPT-6 Astra、Opus 5.5 並列；獨立評測請看 Artificial Analysis 一文。 獨立評測：Artificial Analysis 10/12 公布：Muse Wonder Full（max）Intelligence Index v4.3 得 56（較 Muse Spark 1.3 max 的 48 高 8 分），Muse Wonder（max）得 52。Full 在十項中有六項進前三，Terminal-Bench 4.0 從 33% 升到 57%；CritPt、GDP.pdf 居首。Wonder（max）每項任務約 4.52 美元（輸入高價＋高用量），輸出 token 約 54k／任務、低於 Spark 與多數同檔。知識面 AA-Omniscience 仍偏弱，但幻覺率下降。Coding Agents Index：Full 在 Muse Code 達 68、Wonder 63。廠商自報與 AA 分數不完全相同，規劃請以獨立榜為準。

Gemini Nano Banana 2.1 (gemini-nano-banana-2.1)

【比 2.0 進步在哪】官方說畫質更自然、照文字指示更準、多輪編輯時人物更一致、修好超寬比例（8:1 等）的接縫，可放最多 14 張參考圖；API 價格約砍半（1K 圖 6.7→3.36 美分）。缺點：預設會「先思考」所以比較慢、拿掉 512px 小圖。已上 Gemini App、AI Studio、Flow 等；舊版 API 10/29 關閉。【實測】ppl.studio 盲測：文字 9/9 全對（舊版 7/9）、人臉相似度 40:24 勝；Voyager 12 題：舊版愛自己加字或按鈕，2.1 比較乾淨，但免費 Gemini 方案用不到 2.1；ZOOOP：2.1 照片最不像 AI 圖，能一次做 8:1 橫幅；DEV 社群實測慢約 10–20 秒，建議把 thinking 設 minimal。樣本都不大，屬初步實測。

Strengthening our defenses against distillation attacks

Anthropic 10/12 說明近幾個月對「蒸餾攻擊」的防禦：Claude Fable 5.1／Opus 5.5 對 8/31 後新開的 API 帳號啟用 preserved thinking（不能改寫先前上下文），並加上兩階段分類器；早期數據顯示蒸餾者能抓到的資料減少約 90–99%，誤判率低於 0.1%。代價是部分正常整合需要調整。

MiniCPM-V 4.7 35B-A3B

面壁智能開源 MiniCPM-V 4.7 系列旗艦 35B-A3B（約 3B 啟動參數）與量化／1B 變體，Apache-2.0。主打 Lookahead Expert Scheduling（LES）預載專家、層級量化與 DSpark 推測解碼，官方稱是首款能在端側「不犧牲路由能力」順暢跑的開源 MoE 多模態，iPhone 17 Pro Max 解碼約 13+ token／秒；亦有 iPad M4 示範。支援單圖／多圖／影片、OCR，推理框架含 transformers／vLLM／SGLang／llama.cpp／Ollama，並附 FP8／AWQ／GPTQ／GGUF。權重約 10/7 起上傳，模型卡與授權說明在 10/12 前後補齊。

第一次安裝 ComfyUI（Windows 桌面版）

學會裝好 ComfyUI 並跑出第一張圖，這是本地 AI 生圖／影片的起點。

ComfyUI：用拖拉「節點」組合 AI 生圖流程的免費軟體VRAM：顯示卡記憶體，決定能跑多大的模型

看更多：步驟
  1. 到官方文件下載 ComfyUI Desktop 安裝檔並執行。
  2. 選擇 GPU 類型（NVIDIA 建議）與安裝資料夾。
  3. 開啟後從「範本（Templates）」選一個入門生圖範本。
  4. 依提示下載缺少的模型，按「Run」產生第一張圖。
教學來源：ComfyUI 官方：Windows 桌面版安裝 ↗手動安裝（進階） ↗

在 ComfyUI 跑 Qwen Image 2.1

用官方範本在自己電腦生成 2K 圖、做圖片編輯和去背，也就是你追蹤中的模型。

int8：把模型壓縮成較小的格式，省顯存、畫質略降

看更多：步驟
  1. 先把 ComfyUI 更新到最新版。
  2. 在範本庫搜尋「Qwen-Image-2.1」並開啟。
  3. 從 Hugging Face 的 Comfy-Org/Qwen-Image-2.1 下載模型，分別放進 models/diffusion_models、text_encoders、vae。
  4. 照範本預設（25 步、CFG 1）輸入提示詞後執行。

LoRA 怎麼用：幫模型加風格

學會在 ComfyUI 載入 LoRA，讓同一個模型畫出特定畫風或角色。

LoRA：掛在主模型上的小外掛，用來加風格或修正

看更多：步驟
  1. 下載 LoRA 檔（.safetensors），放進 ComfyUI/models/loras。
  2. 在流程中加入「Load LoRA」節點，接在模型載入節點後面。
