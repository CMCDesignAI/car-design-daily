Meta 發表 Muse Wonder 與 Muse Wonder Full：主打個人／專業代理，Full 僅 Muse Code 訂戶

Introducing Muse Wonder and Muse Wonder Full

Meta Superintelligence Labs 10/12 推出 Muse Wonder 系列：API／Muse Code 可用的 Muse Wonder，以及僅 Muse Code 訂戶可用、分數更高的 Muse Wonder Full。兩者皆標 1M 上下文，輸入含文字／圖／影片／音訊，輸出文字；強調 Active Memory（跨對話記住重點）與 Active Focus（長任務換路徑、遇阻再試、重要動作前確認）。Wonder API 定價每百萬 token 輸入 4／快取 0.20／輸出 20 美元（與 Claude Opus 5.5 同級）。官方自測表把兩款與 Fable 5.1、GPT-6 Astra、Opus 5.5 並列；獨立評測請看 Artificial Analysis 一文。

Artificial Analysis · 閉源 · 評測2026-10-12

AA 實測：Muse Wonder Full（max）Intelligence Index 56、Wonder（max）52，代理與科學推理偏強

Muse Wonder and Muse Wonder Full · Artificial Analysis

Artificial Analysis 10/12 公布：Muse Wonder Full（max）Intelligence Index v4.3 得 56（較 Muse Spark 1.3 max 的 48 高 8 分），Muse Wonder（max）得 52。Full 在十項中有六項進前三，Terminal-Bench 4.0 從 33% 升到 57%；CritPt、GDP.pdf 居首。Wonder（max）每項任務約 4.52 美元（輸入高價＋高用量），輸出 token 約 54k／任務、低於 Spark 與多數同檔。知識面 AA-Omniscience 仍偏弱，但幻覺率下降。Coding Agents Index：Full 在 Muse Code 達 68、Wonder 63。廠商自報與 AA 分數不完全相同，規劃請以獨立榜為準。

MiniCPM-V 4.7：35B-A3B 端側 MoE 多模態，Apache-2.0；宣稱 iPhone 可跑 13+ tok/s

MiniCPM-V 4.7 35B-A3B

面壁智能開源 MiniCPM-V 4.7 系列旗艦 35B-A3B（約 3B 啟動參數）與量化／1B 變體，Apache-2.0。主打 Lookahead Expert Scheduling（LES）預載專家、層級量化與 DSpark 推測解碼，官方稱是首款能在端側「不犧牲路由能力」順暢跑的開源 MoE 多模態，iPhone 17 Pro Max 解碼約 13+ token／秒；亦有 iPad M4 示範。支援單圖／多圖／影片、OCR，推理框架含 transformers／vLLM／SGLang／llama.cpp／Ollama，並附 FP8／AWQ／GPTQ／GGUF。權重約 10/7 起上傳，模型卡與授權說明在 10/12 前後補齊。

Decision 3.0：六款 Apache-2.0 多模態決策模型（0.6B–27B），輸出選項機率而非長文

Decision 3.0 · vllm-sr/d3

Alibaba Qwen · 開源 · 訓練框架（論文）2026-10-12

QwenGyre：超長時程代理的彈性 RL 訓練；論文公開、程式碼尚未釋出

QwenGyre · Elastic RL for xLong-Horizon Agents

阿里 Qwen 團隊提出 QwenGyre：在小時級、近百萬 token 的 agent rollout 上做線上 RL。核心是彈性排程（rollout 與訓練之間動態挪 GPU、KV cache RDMA 遷移）與軌跡處理（分支樹去重、每條執行最多保留 5 條樣本）。在 Qwen 3.8 2.4T 上 NL2RepoBench 48 步從 52.5% 提到 58.5%，相對 Colocate／Async 有最高約 1.85× 加速（論文數字）。目前僅見 arXiv 論文與二次整理，公開程式碼與授權尚未公布，暫列研究向。
