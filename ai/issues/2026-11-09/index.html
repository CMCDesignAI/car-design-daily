Antigravity 可以用講的寫程式了

在 Antigravity App 或 CLI 開語音模式，就能用說的交代任務、中途改方向、口頭核准權限，代理會即時用語音回答。

Gemini Live：Google 的即時語音對話模型，可以直接聽聲音、即時回話、被插話打斷Remote agents：讓代理的對話改在雲端專案執行，不佔用自己的電腦

看更多

Voice mode in Antigravity is here. Enabled by the Gemini Live model, you can use your voice to plan, steer code changes, and approve permissions out loud.

Google 於 11/6 發文介紹 Antigravity 語音模式，由 Gemini Live 模型驅動：直接聽你的聲音（不是先轉文字），可隨時插話打斷，延續當前對話的上下文，代理照常讀程式、改檔、跑指令並把結果顯示在對話中。使用方式：App 裡在空白訊息框按 Start Voice mode 並選聲音；CLI 需 1.5.0 以上，輸入 /voice live 或按 F6。官方文件說明音訊會串流到 Google 伺服器處理，語音模式只能存取開啟它的那個對話，檔案與指令仍走原本權限。v2.29.0 更新日誌（11/3）寫明語音模式逐步推出、可能還看不到；同版也開始向 Google AI Ultra 與 Pro 訂閱者推出在雲端執行對話的 Remote agents。9to5Google 報導語音播放速度可調 0.75x–2x。

NVIDIA · 開源 · 世界模型 · 自駕模擬2026-11-05

Cosmos 3 新增 4 個駕駛／機器人模擬模型

NVIDIA 釋出 4 個以 Cosmos 3 Nano 後訓練的 16B 模型，可生成最多 11 路鏡頭的駕駛影片、同步 LiDAR，或依機器人動作預測畫面，可商用。

世界模型：能根據輸入預測「世界接下來會怎麼變」並生成畫面的模型，常用來做自駕與機器人模擬LiDAR：光達，用雷射測距掃描周圍環境的感測器，自駕車常用

看更多

NVIDIA Cosmos world model development platform adds four new open-weight checkpoints to its Cosmos 3 model family for generating interactive world simulation and multi-sensor multi-view driving scenes.

NVIDIA 在 Hugging Face 部落格（11/5）公布四個新檢查點：Transfer-Auto（依場景地圖與文字改天氣、光線、時段，生成最多 11 路含魚眼鏡頭的同步影片，可同時生成 LiDAR）、Sim-Auto（Transfer-Auto 的串流蒸餾版，幾步去噪就能邊開邊生成相機與 LiDAR 觀測）、Sim-Transfer（把模擬器控制加文字轉成寫實影片）、Sim-Bimanual（依雙臂機器人動作預測影片）。四個都是 16B 可訓練參數，採 OpenMDW 1.1 授權，允許商用與非商用。執行需要 Linux、NVIDIA GPU、Docker；官方的 vLLM-Omni 設定是在一張 GB200 上測試，並註明這不是最低顯存規格。

ComfyUI Ming Image 0.1 Design：生成帶清楚文字、透明背景的版面設計圖

學會用官方模板讓 6B 開源模型做海報、資訊圖、UI 版面，引號裡的字會照寫，還能輸出帶 alpha 透明通道的 PNG。

RGBA：紅綠藍三色再加一個透明度（alpha）通道，背景可以是真正透明提示詞改寫：先用一個語言模型把簡短想法擴寫成詳細版面描述，再交給生圖模型

看更多：步驟
  1. 把 ComfyUI 更新到最新，在 Template Library 搜尋「Ming Image 0.1 Design」打開模板（或從官方頁下載 JSON）。
  2. 依官方頁下載 4 個檔：ming_image_0.1_design_int8_convrot（diffusion_models）、ming_image_0.1_ling_mini_2.0_int8_convrot 與 qwen3.8_27b_w4a8（text_encoders）、ming_image_vae_bf16（vae）。
  3. 進入「Text to Image (Ming Image 0.1 Design)」子圖，在 prompt 逐區描述版面，要出現的文字放在引號裡。
  4. 用 ResolutionSelector 選畫布：2048×2048 品質最好，1024×1024 較快；enable_PE 開著會用 Qwen3.8-27B 擴寫提示詞，關掉則原文照送。
  5. 要透明背景時，在提示詞最前面加「RGBA, 4-channel, transparent background」，按 Run 後在 PreviewImage 看結果。
教學來源：ComfyUI 官方教學：Ming Image 0.1 Design ↗inclusionAI/Ming-Image（GitHub） ↗Ming-Image-0.1-Design 模型卡（Hugging Face） ↗
入門 · VRAM 官方頁寫測試 2B 版本約需 16GB 顯存本週新教學

ComfyUI Cosmos Predict2 Video2World：單張圖片生成符合物理的影片

學會在 ComfyUI 跑 NVIDIA 的 Cosmos-Predict2 2B 圖轉影片，先體驗今天新聞裡 Cosmos 世界模型家族的入門版本。

Video2World：給一張圖（可加最後一格），讓模型預測接下來的畫面並生成影片

看更多：步驟
  1. 更新 ComfyUI，從官方頁下載工作流 JSON（或把官方示範影片拖進 ComfyUI，裡面內嵌了模型下載連結）。
  2. 若自動下載失敗，手動放好：cosmos_predict2_2B_video2world_480p_16fps（diffusion_models）、oldt5_xxl_fp8_e4m3fn_scaled（text_encoders）、wan_2.1_vae（vae）。
  3. 確認 Load Diffusion Model、Load CLIP、Load VAE 三個節點各自載入對應檔案，在 Load Image 上傳輸入圖。
  4. 需要首尾幀控制時按 Ctrl(cmd)+B 啟用最後一幀輸入；可在 ClipTextEncode 改提示詞、在 CosmosPredict2ImageToVideoLatent 改尺寸與幀數。
  5. 按 Run 或 Ctrl(cmd)+Enter 生成。
教學來源：ComfyUI 官方教學：Cosmos Predict2 Video2World ↗nvidia-cosmos/cosmos-predict2（GitHub） ↗Comfy-Org/Cosmos_Predict2_repackaged（Hugging Face） ↗
