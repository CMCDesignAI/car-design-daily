Anthropic · 企業方案2026-11-12

Claude 代理可以自己架了

企業可以把 Claude 的整套代理執行環境裝在自己的伺服器上，資料不出公司，模型請求也能改走 AWS、Google、微軟等雲端。

自架（Self-hosted）：軟體裝在自己公司的伺服器上執行，而不是用供應商的雲端沙箱（Sandbox）：隔離的執行環境，讓代理在裡面跑指令，出事也不影響外面

看更多

Introducing self-hosted Claude Managed Agents. Now you can run agents in your own environment, whether that’s in your own cloud or on-premise.

【是什麼】依 Anthropic 官方文章與文件：Managed Agents（打造長時間自主代理的 API 套件）新增自架模式，代理框架、沙箱、憑證與對話紀錄全部跑在客戶自己的雲端或機房；客戶要自行營運 Managed Agents 伺服器（cma-server）、PostgreSQL 16 以上資料庫，以及執行 shell／檔案工具的 worker。模型請求可直送 Anthropic，或改走 Amazon Bedrock、Google Agent Platform、Microsoft Foundry、自家 gateway；開發 API 與雲端版相同。 【在哪裡能用】私人測試（private beta），要透過 Anthropic 業務團隊申請。 【限制】官方文件提醒：代理的 bash 是真的 shell，隔離要靠你把 worker 放在拋棄式容器或 VM；伺服器、資料庫與防火牆的安全與更新都由客戶負責；部分功能只有雲端版才有。

ComfyUI 圖生圖（Image to Image）入門：拿一張圖當參考，換風格、線稿變實景

學會載入官方圖生圖工作流，並用 KSampler 的 denoise 控制「新圖要離原圖多遠」。

Denoise（去噪強度）：0–1 的數值：越小越像原圖，設成 1 就等於完全重畫、原圖特徵全部消失

看更多：步驟
  1. 下載 v1-5-pruned-emaonly-fp16.safetensors，放進 ComfyUI/models/checkpoints。
  2. 下載官方工作流圖片拖進 ComfyUI 載入（圖片裡含工作流），再下載官方輸入圖。
  3. 確認 Load Checkpoint 選對模型、Load Image 上傳輸入圖，按 Queue（Ctrl/Cmd+Enter）生成。
  4. 調整 KSampler 的 denoise（要小於 1）：數值越小越接近原圖，越大變化越多。
  5. 用途：照片轉插畫風格、線稿轉寫實、修復或替老照片上色等。
教學來源：ComfyUI 官方：Image to Image Workflow ↗
入門 · VRAM 官方頁未列顯存需求；範例用 SD 2 系列的 512-inpainting-ema 模型，依原頁為準常青教學

ComfyUI 擴圖（Outpainting）入門：把畫面往外延伸、補出更大的場景

學會用 Pad Image for outpainting 節點設定往哪個方向擴、擴多少，讓 AI 補出原圖外的畫面。

Outpainting（擴圖）：把畫布往外加大，讓 AI 依原圖內容補出新的區域Feathering（羽化）：讓原圖和新補區域的交界過渡更平順的參數

看更多：步驟
  1. 下載 512-inpainting-ema.safetensors，放進 ComfyUI/models/checkpoints。
  2. 下載官方工作流圖片拖進 ComfyUI 載入，Load Image 上傳要延伸的圖。
  3. 在 Pad Image for outpainting 節點設定 left／top／right／bottom 各要擴多少像素，feathering 調大可讓接縫更自然。
  4. 按 Queue（Ctrl+Enter）生成；官方說明這其實是 inpaint 工作流，只是用這個節點自動產生遮罩。
  5. 用途：延伸場景、調整構圖、在畫面旁補上相關元素。
教學來源：ComfyUI 官方：Outpainting ↗
