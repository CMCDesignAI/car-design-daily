MiniMax H3

ComfyUI 0.39 官方強化，社群工作流可逐秒控制

  1. 2026-10-08

    Stubelius Ultimate H3 0.11：中間影格、接續影片、釘選音效

    免費、MIT 授權的 ComfyUI 工作流包 Stubelius Ultimate H3 更新到 0.11，在 First/Last Frame 模式加入三種時間軸控制：最多兩張「中間影格」讓影片在指定秒數到達某個畫面；把一段影片丟進 First Frame 欄位就能接著續拍（搭配 ComfyUI-H3-Motion-Context-MultiRef，會帶入最後 1.6 秒的畫面和聲音）；最多 8 段音效或短片釘在指定秒數。作者實測對白能對到約 40 ms 內，但單靠音效無法讓角色動作對時，需搭配中間影格。片段會自動對齊 H3 的 17 影格網格（每 0.71 秒）以避免灰畫面。也修掉取消算圖後的記憶體洩漏。

    Stuubzzz 部落格 ↗YouTube 示範 ↗
  2. 2026-10-06

    ComfyUI v0.39.0：H3 輕量 VAE、LoRA 相容與多項修正

    ComfyUI 0.39.0 正式版（台灣時間 10/6 清晨發布）加入 LynnReal 輕量版 MiniMax H3 VAE 支援、修正 MiniMax VAE 卸載問題、在區塊執行前釋放 H3 嵌入暫存以降低記憶體。The Signal 整理指出，這版也支援用 DiffSynth-Studio／魔搭（ModelScope）訓練的 H3 與 HiDream O1 LoRA。同版還修正 Qwen Image 2.1 選 int8／int4 快取時的當機，並把 Save Video 預設編碼改成較高畫質。

    GitHub Release v0.39.0 ↗The Signal 解析 ↗

Qwen Image 2.1

社群 LoRA 持續擴充：修復、視角環繞

  1. 2026-10-07

    Qwen Image 2.1 Restore LoRA：修圖不再「換一張臉」

    社群作者 ausboss 在 Hugging Face 和 Civitai 發布修復用 LoRA（rank 32，無觸發詞），目標是放大修復時保持原本的人臉、顏色和構圖，不亂加皺紋毛孔。作者自測 8 張圖：畫面偏移從 2.35 px 降到 0.26 px，SSIM 從 0.578 升到 0.766；57 張受損圖全部勝過原版。作者也坦承 SeedVR2 畫質幾乎打平、速度快約 6 倍，LoRA 的優勢在嚴重 JPEG 壓縮。需要 ComfyUI 0.38 以上與 AusBoss 自訂節點，可搭配 Viggle Turbo 跑 8 步；模糊照片建議強度降到 0.5。

    ArtRealmAI ↗
  2. 2026-10-08

    Hugging Face 用 ML Intern 訓練 Qwen-Image 2.1 視角環繞與塗鴉 LoRA

    Hugging Face 官方部落格示範用 HuggingChat 的 ML Intern 代理從描述需求到訓練出模型。成果包括 Qwen-Image 2.1 的 Viewpoint Orbit LoRA（約 16 美元算力）、Doodle-in LoRA（約 24.3 美元），以及把 Qwen-Image 2.1 內建的提示詞改寫模型蒸餾成 0.8B／2B 的 Pocket Rewriter（0.8B 另有 812 MB GGUF 可在 CPU 跑，有效輸出率 99.7%）。整個專案總算力約 103 美元。

Krea 2

官方無新權重；工具整合與社群風格庫

  1. 2026-10-05

    Krea for After Effects：在 AE 裡直接生圖、做動態設計

    Krea 推出 After Effects 外掛（macOS 12／Windows 10 以上、AE 2025 以上），從 Window → Extensions → Krea 開啟，可在合成裡生成素材、背景板、動態設計方向，並用 Krea Realtime 即時預覽；生成結果會成為一般媒體素材放進專案。需登入 Krea 帳號、在雲端運算。這和前天報導的 Photoshop 外掛同屬 Krea 外掛系列，Krea 2 是可用的模型之一。

    Krea 官方頁 ↗AlphaSignal ↗
  2. 2026-10-05

    社群整理 Krea 2 的 500 種純提示詞風格庫

    Reddit r/StableDiffusion 使用者 u/Dear-Spend-2865 釋出 Krea 2（含 Turbo）的 500 種風格提示詞，以試算表和 wildcard .txt 發布，不用載入 LoRA 就能切換畫風。搭配 GitHub 上 lumenastrum 的 ComfyUI 擴充 clio-style-preview，可在同一個 seed 下並排比較各風格。線上圖庫目前只收錄約 280–397 種，完整 500 種要匯入 txt；部分風格對臉部敏感，需在提示詞補臉部描述。

JetBrains 開源 Mellum2.1：給程式代理用的 12B MoE 小模型

Mellum2.1 Gets to Work: A Fast Open Model for Coding Agents
