Build more responsive apps with the Decisions API

OpenAI 10/22 宣布 Decisions API 從公開測試轉為正式版（GA）。【是什麼】開發者先定義一個問題和允許的答案，再丟入文字、圖片或 JSON，API 只回三種結果之一：predicate（某條件成立的機率 0–1）、choice（從你給的選項挑一個，附機率與信心）、score（依評分等級打分）。官方說它把 GPT-6 Luna 的能力集中在「答案範圍固定」的問題上，比透過 Responses API 呼叫 GPT-6 Luna 快最多 10 倍。【比測試版多了什麼】原生整合 GPT-Live 語音（對話中即時決定要追問、轉接或升級處理）、可重複使用內容的提示快取、美國與歐盟的推論資料駐留、原生 JSON 輸入、題目說明可附圖，每次請求最多 400 題（是之前的 2 倍），亞洲數個地區也加了算力。【價格】輸入每百萬 token 0.10 美元、快取輸入 0.01 美元，沒有輸出費用。【客戶說法】Datadog 說 p95 延遲比其他前沿模型快 40 倍、準確度相當；Sierra 說 p95 低於 280 毫秒、每次成本降約 90%；以上皆為官方頁引用的客戶自述。

來源：OpenAI 官方：Build more responsive apps with the Decisions API ↗

Gemini app expands Personal Intelligence Google Maps integration

@GeminiApp 10/22 宣布：在你同意下，Gemini 現在能參考你在 Google 地圖的搜尋紀錄與已儲存地點，並搭配 Google 行事曆給出當天的建議。9to5Google 舉的官方範例是問「我有一份想去的餐廳清單，今天開完會後去哪間最好？」，Gemini 會看你最後一場會議在哪，再從已儲存地點挑附近的。【怎麼開】到 gemini.google.com/personalization-settings 開啟 Personal Intelligence（個人化智慧）。【限制】Google 官方說個人化智慧目前開放給 18 歲以上的個人 Google 帳號（不含 Workspace 企業／教育帳號），不含歐洲經濟區、瑞士、英國與奈及利亞。【另一則異動】9to5Google 也報導，Google 正通知 AI Ultra 訂閱者 Gemini 4 Argon 將「很快取代 Deep Think」，需要深度推理時改用 Argon；Google 說明中心也寫 Deep Think 正由 Argon 取代。

ComfyUI 工作流程範本（Templates）：不用自己接線，挑一個範本就能開跑

學會從內建範本庫載入官方工作流程，並讓 ComfyUI 自動提示、下載缺少的模型檔。

工作流程（Workflow）：ComfyUI 裡一整組連好線的節點，決定圖片或影片怎麼產生safetensors：目前最常見、較安全的模型檔格式

看更多：步驟
  1. 在 ComfyUI 左側欄點「Templates」圖示，或從選單 Workflow → Browse Workflow Templates 打開範本庫。
  2. 點選想用的範本（官方原生支援的模型，或自訂節點的範例），工作流程會直接載入畫布。
  3. 如果缺模型，相關的載入節點會變紅，並出現「N errors found」提示；點 View details，在右側面板 Errors 分頁的 Missing Models 清單可以逐一 Download 或 Download all。
  4. Desktop 版會自動存到對應的 ComfyUI/models/ 資料夾；瀏覽器自架版會改成用瀏覽器下載，要自己把檔案放進對應資料夾（例如 diffusion_models、vae、text_encoders）。
  5. 模型、輸入圖和提示詞都準備好後，按 Run 開始生成；若模型其實放在子資料夾，可關掉提示，直接在載入節點裡選那個檔案。

Wan2.1 FLF2V：給第一張和最後一張圖，讓 ComfyUI 自動補出中間的 720p 影片

學會用官方原生工作流程，放入起始幀與結束幀兩張圖，生成兩者之間自然過渡的影片（適合做造型變化、場景轉換）。

FLF2V（首尾幀生成影片）：First-Last Frame to Video：只給開頭和結尾兩張圖，模型自己生成中間的動態FP8：把模型數字壓成 8 位元的版本，比 FP16 省顯存，畫質略有差異

看更多：步驟
  1. 先把 ComfyUI 更新到最新版，再到 Workflow → Browse Templates → Video 找「Wan2.1 FLF2V 720P」，或從官方頁下載工作流程 JSON 拖進 ComfyUI。
  2. 下載模型（官方頁都有連結）：擴散模型 wan2.1_flf2v_720p_14B 選 fp16 或省顯存的 fp8 版，放 models/diffusion_models/；文字編碼器 umt5_xxl（fp16 或 fp8）放 models/text_encoders/；wan_2.1_vae 放 models/vae/；clip_vision_h 放 models/clip_vision/。
  3. 在兩個 Load Image 節點分別放入起始幀與結束幀（可先用官方提供的範例圖）。
  4. 確認各載入節點選到剛下載的檔案，輸入提示詞描述中間的變化，按 Run 生成。
  5. 顯卡吃不消時先調小影片尺寸測試，但官方提醒尺寸太小效果可能不好。
