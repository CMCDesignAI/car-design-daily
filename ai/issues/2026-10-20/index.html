MiniMax M3.1 Flash: Redefining Agent Performance and Cost

MiniMax 10/19 正式推出新一代 Flash 模型 M3.1 Flash，官方說先前以匿名身分處理超過 200 兆 token 的「Space Bunny」就是它的早期版本。【比上一版進步在哪】官方稱在代理任務、寫程式、電腦操作（Computer Use）和資安上是「世代提升」，線上推論快近 3 倍，代理任務整體使用成本比前代低 70%；日常輸出速度可達每秒 200+ token、中位數 170+。【成績（官方自測）】DeepSWE v1.1 73.7%、OSWorld V2 61.7、Agents’ Last Exam 29.6（兩項皆稱中國模型第一）、BankerToolBench 76.2、CyberGym 82%。【價格】每百萬 token 輸入 0.15 美元、輸出 0.60 美元、快取輸入 0.015 美元。【哪裡能用】MiniMax API、M Plan 方案與桌面版 MiniMax Code；權重「之後釋出」，更強的 Pro 版也會晚點推出。目前尚無獨立實測。

Advancing coding in low-resource programming languages

OpenAI 10/19 發文說明最新模型在「低資源程式語言」（網路上程式碼和文件很少的語言，如 COBOL、Fortran、Visual Basic、OCaml）的進步；這些語言仍撐著銀行、政府和企業的關鍵系統。【兩個新評測】MultiLangBench 要模型用 20 種語言從零寫出相容 SQLite 的資料庫引擎；COBOL 遷移評測要把 COBOL 程式改寫成 C++、Java、Kotlin、Python 或 Rust，且輸出要逐位元組一致。【成績（官方自測）】GPT-6 Astra 在 MultiLangBench 平均通過率 87.4%（GPT-5.6 Sol 為 26.8%），COBOL 從 10.9% 升到 72.1%、Fortran 21.4%→83.5%；較便宜的 GPT-6 Luna 達 40.3%，估計 API 成本約低 78%。COBOL 遷移評測上 GPT-6.1 Sol 低推理強度 86.6%（GPT-5.6 Sol 僅 5.4%）、成本少 39%，高推理強度達 97.9%。【限制】官方提醒用在正式系統仍需專家審查和測試。【哪裡能用】透過 API 使用最新模型；評測與測試集已放上 GitHub。

fal 10/19 推出 FLUX 3 Max，是 fal Research 與 Black Forest Labs 合作、以 FLUX 3 影片基礎模型再訓練（後訓練）並優化推論的版本。【比上一版進步在哪】在 Artificial Analysis 圖生影片競技場（初步結果）拿到 1,139 Elo，比原版 FLUX 3 的 1,089 高 50 分，與 Seedance 2.5 同分、信賴區間和第一名重疊（官方頁註明 MiniMax H3 以 1,141 排該榜第一）；生成 10 秒影片新聞稿寫 10.95 秒、官方頁寫 12.45 秒，比 FLUX 3 的 126.44 秒快約 10 倍，比 Seedance 2.5 的 277.80 秒快約 22 倍。【限制】首發只有文生影片和圖生影片兩個端點、720p；原版 FLUX 3 的草稿、關鍵影格、延長功能不在其中。【價格】按輸出秒數計費，720p 原價每秒 0.17 美元，11/7 前打 2.5 折為 0.0425 美元。【哪裡能用】fal 平台 API 與 Playground。目前只有官方與 Artificial Analysis 初步數字，尚無獨立實測比較。

幫 ComfyUI 安裝擴充節點：Manager、git clone、ZIP 三種做法

學會安全地裝上別人做好的擴充節點，並把它需要的 Python 套件裝在正確的環境裡。

擴充節點（Custom Nodes）：社群做的外掛，幫 ComfyUI 加上原本沒有的功能相依套件：擴充節點要能跑起來，另外需要安裝的 Python 程式庫

看更多：步驟
  1. 先看擴充節點的 README，確認作者可信、用途和需要的模型或套件版本；官方提醒不要裝來路不明的節點。
  2. 最推薦：用 ComfyUI Manager（新版多已內建）搜尋並安裝，它會自動處理相依套件。
  3. Manager 找不到時改用 git：進到 ComfyUI/custom_nodes 資料夾，執行 git clone 加上 GitHub 的 HTTPS 網址。
  4. 安裝相依套件：可攜版用 python_embeded\python.exe -m pip install -r 該節點的 requirements.txt；手動安裝版在 ComfyUI 的環境裡 pip install -r requirements.txt。
  5. 重新啟動 ComfyUI 並重新整理瀏覽器，看啟動訊息有沒有 import failed；不會用 git 才考慮下載 ZIP 解壓到 custom_nodes（但失去版本控管）。
教學來源：ComfyUI 官方：How to Install Custom Nodes ↗
入門 · VRAM 官方頁未標示（範本用 fp8 版模型，依原頁為準）常青教學

在 ComfyUI 用 FLUX.1 Kontext Dev 改圖：一句話換顏色、換背景、改字

用官方範本載入 Kontext Dev，用英文指令局部改圖，並保持人物和構圖不變。

圖像編輯模型：給它一張圖加一句指令，它只改你說的地方，其他部分盡量保持原樣fp8：把模型數字存得比較精簡的版本，檔案更小、比較省顯存

看更多：步驟
  1. 先把 ComfyUI 更新到新版，在範本庫搜尋「FLUX Kontext Dev」打開官方工作流程。
  2. 照官方頁下載模型：flux1-dev-kontext_fp8_scaled（放 diffusion_models）、ae.safetensors（放 vae）、clip_l 與 t5xxl（放 text_encoders）。
  3. 在各載入節點確認選到對應檔案，再於 Load Image(from output) 放入要改的圖。
  4. 在 CLIP Text Encode 用英文寫指令（官方說只支援英文），例如 Change the car color to red，按 Queue 執行。
  5. 訣竅：說清楚要保留什麼（keep the person in the exact same position）、複雜修改拆成幾步、改字時把文字加引號。
教學來源：ComfyUI 官方：FLUX Kontext Dev 原生工作流程 ↗
