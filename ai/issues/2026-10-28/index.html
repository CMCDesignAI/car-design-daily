Genie 4: A new generation of world simulation

【比上一版進步在哪（官方說法）】Genie 4 接替 Genie 3，畫面更寫實、物理（空氣動力、碰撞）更自然，人物動作與反應也更像真人；第一次原生生成聲音，包括環境音、音樂和會依你的操作即時改變的角色對話。可以在模擬進行中用一句話改天氣、移動鏡頭、加入人物或物件，由 Gemini 負責理解指令並維持場景連貫。據 TechCrunch 與 The Verge，場景可維持約 2 分鐘，是 Genie 3 的兩倍。【限制】官方坦承時間一久細節與物件會漂移，複雜物理、聲音準確度、畫面中的文字仍在改進。【哪裡能用】目前只開放給受邀測試者做研究預覽；接下來先給 Google AI Ultra 訂閱者在 Project Genie 使用（已開放候補名單），以及 Gemini API／AI Studio 的早期合作夥伴，API 價格尚未公布。【實測】目前只有媒體看過官方展示，還沒有一般使用者的實測比較。

Z-Image-Turbo：8 步就出圖、中英文字都寫得準的輕量生圖模型

學會在 ComfyUI 載入官方範本，用 3 個檔案跑起阿里通義的 Z-Image-Turbo，快速生成含中英文字的圖。

蒸餾版（Turbo）：把大模型壓縮訓練成只要很少步數就能出圖的快速版本文字編碼器：把你的提示詞翻成模型看得懂的數字的元件

看更多：步驟
  1. 把 ComfyUI 更新到最新版，在範本庫（Workflow → Browse Templates）找「Z-Image-Turbo」；找不到通常是版本太舊。
  2. 下載 3 個檔案：文字編碼器 qwen_3_4b.safetensors 放 models/text_encoders/，主模型 z_image_turbo_bf16.safetensors 放 models/diffusion_models/，VAE ae.safetensors 放 models/vae/。
  3. 開啟範本，在提示詞框寫你要的畫面，可以直接用中文，也能要求圖上出現指定的中英文字。
  4. 步數維持範本預設（官方說 8 步就夠），按 Run 生成；想控制構圖，同一頁還有 Fun Union ControlNet 範本，支援線稿、深度、骨架等控制。
教學來源：ComfyUI 官方文件：Z-Image-Turbo ↗Hugging Face 模型卡 ↗

BiRefNet：在 ComfyUI 一鍵去背，頭髮毛邊也乾淨

學會用 ComfyUI 內建的 BiRefNet 範本，把照片背景去掉，輸出透明背景圖和遮罩，方便後續合成。

遮罩（Mask）：一張黑白圖，標出哪裡是主體、哪裡要去掉RGBA：多了透明度通道的圖片格式，背景可以是透明的

看更多：步驟
  1. 把 ComfyUI 更新到最新版，在範本庫的 Utility 分類找「BiRefNet: Remove Background」。
  2. 下載 birefnet.safetensors，放到 ComfyUI/models/background_removal/（注意不是 checkpoints 資料夾）。
  3. 在 Load Image 節點上傳要去背的圖片（人像、商品、動物都可以），按 Run。
  4. 輸出有兩個：去背後的透明背景圖（RGBA）和前景遮罩，可以直接存檔，或接到其他節點做合成、改圖；背景太雜或主體和背景顏色太接近時效果會變差。
