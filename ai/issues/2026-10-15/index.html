Introducing Grok Voice 3.0

xAI（現稱 SpaceXSI）10/14 推出 Grok Voice 3.0，是直接「聽語音、回語音」的對話模型。【比上一版進步在哪（官方引用 Artificial Analysis 10/13 數據）】綜合 Speech-to-Speech Index 86.9（2.0 為 81.3，GPT-Live-1 83.2、Gemini 3.8 Live 82.6）；盲測偏好 Elo 1070（2.0 為 1011）；處理停頓、插話的 Full Duplex Bench 97%（2.0 為 95.1%）；首次回應不到 1 秒。τ-Voice 客服通話測試 71.6%，與 GPT-Live-1 相當但延遲低 40%。【價格／在哪能用】Voice Agent API 每分鐘 0.08 美元（每小時 4.8 美元），與 2.0 相同；用 grok-voice-latest 的程式已自動升級，API 不變；grok-voice-2.0 列為淘汰。也是 Tesla 車上語音與 Grok Bot 語音模式的底層。官方稱 Starlink 客服每天用它接 2 萬通電話，約 70% 不需真人。【實測】以下為第三方評測，屬初步、樣本有限：Cekura 3,198 通電話比較認為它在穩定度、反應速度與成本勝過 GPT Realtime 2.1，但回答準確度較弱。

ComfyUI 圖生圖：拿一張圖當參考，生成新版本

學會用 denoise 數值控制「新圖跟原圖要多像」，做風格轉換或線稿上色。

圖生圖（img2img）：給 AI 一張參考圖加文字描述，讓它畫出新版本denoise：重繪強度：越小越像原圖，1 就等於完全重畫

看更多：步驟
  1. 下載 v1-5-pruned-emaonly-fp16.safetensors，放到 ComfyUI/models/checkpoints。
  2. 把官方頁的工作流程圖片拖進 ComfyUI，載入流程。
  3. 在 Load Image 節點上傳你的參考圖，按 Queue（Ctrl+Enter）生成。
  4. 在 KSampler 把 denoise 從 1 慢慢往下調，比較新圖和原圖的差別。

中階 · VRAM 依模型與量化等級而定（原頁未列固定數字）常青教學

用 GGUF 量化模型，讓小顯卡也能跑大模型

學會安裝 ComfyUI-GGUF 外掛，用壓縮過的 .gguf 模型檔取代原本的大檔，省顯存。

量化（GGUF）：把模型的數字精度降低、檔案變小，用較少顯存換一點畫質

看更多：步驟
  1. 把 ComfyUI-GGUF 用 git clone 到 ComfyUI/custom_nodes，並執行 pip install --upgrade gguf（Windows 免安裝版請照 README 用 python_embeded 安裝 requirements）。
  2. 下載想用模型的 .gguf 檔，放到 ComfyUI/models/unet。
  3. 在工作流程中，把原本的 Load Diffusion Model 換成 bootleg 分類下的 Unet Loader (GGUF)。
  4. 需要時文字編碼器也可換成 CLIPLoader (gguf) 進一步省顯存；LoRA 屬實驗性支援。
