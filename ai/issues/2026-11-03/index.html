OpenAI's new Locked Chats feature allows you to protect selected conversations without deleting them.

【內容】依 Fox News 報導，ChatGPT 新增 Locked Chats：選定的對話可用 4 位數 PIN 保護，支援的裝置也能用 Face ID、Touch ID 或手機解鎖方式。鎖起來的對話會移到「Projects > Locked chats」，從一般對話紀錄、釘選和搜尋結果中消失，打開後可以繼續聊。【注意】如果對話原本在某個 Project 裡，鎖定後會離開該 Project、失去它的指示、檔案和記憶，解鎖後也只會回到一般紀錄。OpenAI 表示這不是端對端加密，也不改變資料保存期限與「改善模型」設定。【開放範圍】逐步開放給 Free、Go、Plus、Pro、Business、Enterprise、Edu，網頁、iPhone／Android App、新版 Mac／Windows 桌面 App 都能用；ChatGPT for Healthcare 不支援。

Claude API 長對話變快

用 Claude 做長時間自動化工作的開發者，不用每回合重傳整段對話，回應開始得更快，但費用不變。

TTFT：Time to first token，送出請求到 AI 開始吐出第一個字的等待時間

看更多

Message threads is now available in public beta on the Claude Platform.

【內容】Anthropic 官方文章：Messages API 加上 thread 參數後，第一次請求送完整對話、建立 thread，之後每次只送新訊息加上前一個回應的 ID。官方說 Claude Code 多數用戶已預設開啟，500k～1M token 的請求首字等待時間（TTFT）中位數下降約 35%。【限制】thread 存在記憶體、加密不寫入磁碟，最後一次請求後 5 分鐘過期（之後要重送完整對話），release notes 寫最多 1 小時內刪除；Claude 每回合仍讀完整對話，所以 token 用量和價格不變。【哪裡能用】Claude Platform、Claude Platform on AWS、Microsoft Foundry、Google Cloud（Anthropic 託管），需加 beta 標頭 message-threads-2026-08-12。依 The Next Web，threads 不適用零資料保留（ZDR）與 HIPAA 設定。

T8 的 H3 換角復刻 Skill

想把熱門影片裡的人換成自己角色的人，可以用 T8 整理的 Skill 讓 AI 代理自動跑完分段生成、檢查和合片。

  • APT 換角 Skill README（v1.2.1，以 wuwukasi 原版整理優化）：給 Codex 兩張人物參考圖和自己的 RunningHub API Key，就能替換固定 APT 原片中的人物，輸出保留原音軌、約 96.6 秒的 1920×1080 影片；44 段原片中實際生成 40 段。
  • 安裝方式：下載完整技能包 ZIP 放到 Codex 的技能目錄，另裝 Python 3.10+、FFmpeg 和 ffprobe，再在 Codex 新對話呼叫 $apt-character-replacement；README 註明這包只適用固定 APT 素材，其他影片要另做鏡頭分析。
  • 另一個「視頻換角與專屬技能工廠」README（v1.4.0，11/2 更新）：給任意原影片和人物參考圖，會分析原片、換人、檢查修復畫面並組裝成片，再產生該影片專屬的可重用 Skill；每段生成不超過 10 秒，1.4.0 新增可選的本機 ComfyUI／H3 後端。
  • README 也註明：1.4.0 只用合成素材和模擬服務驗證，未實際呼叫 H3／GPU 或付費生成；用 RunningHub 雲端生成需要自己的帳號與 API Key。

教學區

Learn
中階 · VRAM 官方文件未標顯存數字（使用 22B int8 蒸餾版）；選用的提示詞增強模型約 5GB，依原頁為準常青教學

LTX-2.5：在 ComfyUI 用文字或圖片生出有聲影片（含首尾幀與多鏡頭）

學會載入 ComfyUI 官方 LTX-2.5 範本，下載對的模型檔放到對的資料夾，用一段文字同時生成畫面和聲音。

FLF2V：給第一格和最後一格圖片，讓 AI 補出中間的影片Gated 模型：Hugging Face 上要先同意授權、等核准才能下載的模型

看更多：步驟
  1. 先把 ComfyUI 更新到最新版，到 Template Library > Video 選一個 LTX-2.5 範本（T2V、I2V、FLF2V 或 DFR）。
  2. 到 Hugging Face 的 Lightricks/LTX-2.5（和 Pixel-Spatial-Upscaler）頁面同意授權並等核准，否則下載會失敗。
  3. 下載模型：ltx-2.5-22b-distilled int8 放 models/diffusion_models/，gemma4-12b 文字編碼器放 models/text_encoders/，影片與音訊兩個 VAE 放 models/vae/，2 倍空間放大模型放 models/latent_upscale_models/。
  4. 提示詞寫成一整段：鏡頭種類、場景、動作、角色、運鏡，加上需要的聲音或對白，模型會一起生成同步音訊。
  5. 想把短提示詞自動擴寫，可在 LTX-2.5 節點開 prompt_enhance（需另下約 5GB 的增強模型，生成多約 1–2 分鐘）。
教學來源：ComfyUI 官方文件：LTX-2.5 ↗Hugging Face：Lightricks/LTX-2.5 ↗
入門 · VRAM 官方文件未標數字；有 Small／Base／Large 四種大小，顯卡小先用 Small（依原頁為準）常青教學

Depth Anything 3：在 ComfyUI 從照片或影片做出深度圖

學會用 ComfyUI 內建的 Depth Anything 3 節點，把一張照片或一段影片轉成深度圖，可拿去搭配 Depth ControlNet 或 3D 用途。

深度圖：用黑白深淺表示畫面中每一點離鏡頭多遠的圖Metric 深度：以公尺為單位的真實距離，而不是相對遠近

看更多：步驟
  1. 先把 ComfyUI 更新到最新版（已內建 Depth Anything 3 節點）。
  2. 從 Hugging Face 的 Comfy-Org/Depth-Anything-3 下載模型，放到 ComfyUI/models/geometry_estimation/：Small 最快、Base 平衡、Mono-Large 單張深度最好、Metric-Large 輸出公尺單位。
  3. 在 Workflow Templates 搜尋「Depth Anything 3: Image Depth Estimation」載入範本（或下載官方 JSON）。
  4. 在 LoadImage 上傳照片、LoadDA3Model 選模型，按 Queue 或 Ctrl+Enter，就會輸出深度圖和左右對照。
  5. 影片版範本會用 GetVideoComponents 拆成單格、逐格算深度再用 SetVideoComponents 組回影片。
教學來源：ComfyUI 官方文件：Depth Anything 3 ↗GitHub：ByteDance-Seed/Depth-Anything-3 ↗Hugging Face：Comfy-Org/Depth-Anything-3 ↗
