Introducing Claude Duet

Anthropic 10/21 開放 Claude Duet 研究預覽，這是獨立於 Claude 主 App 的新 App，定位是「主動型代理」，鎖定專業工作者和小老闆。【能做什麼】每天早上看你的信箱和行事曆，挑出最需要處理的事，並可先擬好回覆給你審；你用打字或語音交代任務，它自己決定用哪些已連結的 App、背景完成，大型成果（研究簡報、財務模型、簡報、儀表板）會以檔案交回；沒有連接器的網站用它自己的雲端瀏覽器處理。它延用你在 Claude 的記憶、技能和連接器，寄信、付款、簽文件、刪除前會先問你。【限制】不能選模型（固定 Claude Opus 5.5）、不能看它操作瀏覽器、每隔幾小時才檢查一次帳號（緊急事可能漏接）、不能打電話傳簡訊、不能交易證券或轉帳，Microsoft 365 暫不支援；官方也說它可能誤讀對話或誤判輕重緩急，訂票等私人雜事較弱。【哪裡能用、多少錢】iOS、Android 與 claude.ai；目前只開放美國的 Pro、Max 訂閱者排候補名單，分批發邀請，Team／Enterprise 之後才有。包含在 Pro／Max 方案內，但會吃同一份用量額度，背景檢查和大型任務也算。

OpenAI models are coming to Google Cloud

OpenAI 與 Google Cloud 10/21 宣布合作，把 OpenAI 的前沿模型和 Codex 代理工作流程帶進 Google Cloud 的 Model Garden。【有哪些】GPT-6 Astra（寫程式、操作電腦、專業與科研等高難度工作）、GPT-6.1 Sol（接近 Astra 的能力、成本較低）、GPT-6 Luna（快速、便宜的日常大量工作）。【怎麼用】今天起對部分企業客戶私人預覽，可用 Google Cloud API 呼叫，本機的 Codex CLI 與桌面版也能直接連到 Google 的 Gemini 平台推論；透過 Google Cloud Marketplace 計費，費用併入同一張 Google Cloud 帳單、可抵用既有雲端承諾額度。官方說資料留在客戶的資料邊界內、不拿來訓練，零資料保留與機密運算「即將推出」。【之後】正式開放預計「未來幾週」，之後也會進 Gemini 企業版（Gemini for business／Gemini Agent）與 Google Antigravity。CNBC 指出這讓 OpenAI 模型同時上了微軟、Amazon、Google 三大雲；OpenAI 表示微軟仍是主要雲端夥伴。一般 ChatGPT 使用者不受影響。

安裝 Forge Neo（sd-webui-forge-classic neo 分支）：用表單式 WebUI 跑新模型

照官方 README 在 Windows 裝好 Forge Neo，之後就能在網頁介面跑 MOSS-Image、Qwen-Image-2.1、Krea 2 等模型。

uv：一個很快的 Python 套件安裝工具，Forge Neo 推薦用它建立環境venv：專屬這個專案的 Python 環境，不會和電腦裡其他程式打架

看更多：步驟
  1. 先安裝 git（官方 Wiki 的 Extra Installations 頁有教學）。
  2. 在想放的資料夾開命令列，輸入：git clone https://github.com/Haoming02/sd-webui-forge-classic sd-webui-forge-neo --branch neo
  3. 官方推薦：安裝 uv，進入 sd-webui-forge-neo 資料夾後執行 uv venv venv --python 3.13 --seed，並在 webui-user.bat 加上 --uv 參數（舊方法是自己裝 Python 3.13.12 並勾選 Add Python to PATH）。
  4. 雙擊 webui-user.bat 啟動；第一次會自動安裝所有需要的套件，完成後瀏覽器會自動打開 WebUI。
  5. 模型要放哪、每個模型建議的參數，看官方 Wiki 的 Download Models 與 Inference References；AMD、Linux、macOS 請看 README 裡對應的指南。

入門 · VRAM 編輯器本身不吃顯存；之後跑局部重繪的需求依所用模型而定常青教學

ComfyUI 遮罩編輯器（Mask Editor）：不用 Photoshop，直接在 ComfyUI 畫遮罩

學會打開內建遮罩編輯器、用筆刷和油漆桶標出要重畫的區域，供局部重繪使用。

遮罩（Mask）：在圖上塗出「這裡要改」的區域，模型只會重畫被塗到的地方

看更多：步驟
  1. 在工作流程裡放一個 Load Image 節點並載入圖片。
  2. 三種打開方式擇一：選取節點後點上方工具列的遮罩圖示；滑到圖片預覽左上角點 Edit or mask image；或對 Load Image 按右鍵選 Open in Mask Editor。
  3. 左側選 Mask Pen 按住左鍵塗出要改的區域；大面積同色區域可用 Paint Bucket 一次填滿，塗錯用 Eraser 擦掉。
  4. 上方工具列可以復原／重做、反轉或清除遮罩，滿意後按儲存回到工作流程。
  5. 接著把這張帶遮罩的圖接到局部重繪（inpaint）流程，就只會重畫你塗的區域。
