AWS 示範 AI 車身設計流程

工程師用聊天方式叫 AI 生成或修改車身，AI 再分頭算風阻、結構可行性和製造成本，幾秒內比較多個版本。

代理模型（Surrogate model）：用大量舊模擬結果訓練的 AI，能在幾秒內估出原本要算好幾小時的風阻或受力結果CFD：計算流體力學，用電腦模擬空氣流過車身，算出風阻與升力

Accelerate design space exploration with AI on AWS

【誰在做】AWS for Industries 官方部落格（美西 11/13 發布，台北 11/14）示範的參考做法，不是特定車廠的量產案例。 【用了哪些 AI】主控用 Amazon Bedrock 上的 Anthropic Claude，搭配 Strands Agents SDK 與 Bedrock AgentCore；2D 概念預覽圖用 Stable Diffusion 3.5 Large；風阻用 AWS 開源的 MLSimKit 代理模型（surrogate model，用既有模擬資料訓練）取代耗時數小時的 CFD。 【流程怎麼走】工程師在網頁聊天介面下指令 → 主控代理分派給四個專職代理：Geometry（依離地高度、尾部斜角、擴散器角度、前懸、船尾角等參數生成轎車／跑車／SUV 等車身，或用一句話加後照鏡、尾翼）、Aero（預測 Cd 等係數並畫表面壓力圖）、Structural（直接分析 3D 網格，依鋼、鋁、碳纖給重量、剛性、建議板厚）、Cost（經 MCP 取材料、沖壓、模具成本算出每版成本）→ 主控彙整成一份比較結果。先出 2D 預覽讓人確認，再做 3D。 【限制】官方文章是技術示範與架構說明，沒有公布實際車廠導入成效；代理模型的預測仍需傳統模擬／實測驗證。

Google · 新功能2026-11-13

Antigravity 能一次指揮一群代理

輸入 /run-workflow 加任務，Antigravity 會寫一支小腳本把工作拆給多個代理同時做，你核准後在背景跑完再彙整結果；AI Pro 就能用。

子代理（Subagent）：由主 AI 派出去做一小塊工作的另一個 AI，做完把結果交回來

看更多

This release adds Dynamic Workflows, letting agents orchestrate parallel subagents and multi-step tasks in Python using the runtime bundled with the app.

【是什麼】依 Google Antigravity 官方 changelog（11/13，App v2.32.0）與說明文件：代理會讀內建的 run-workflow 技能寫出 Python 腳本，用 parallel() 平行、pipeline() 依序執行多個代理，分成具名階段即時顯示進度；每個子代理在自己的對話裡工作、回傳符合 JSON Schema 的結構化結果，主對話不會被大量檔案與日誌塞滿；可把好用的腳本存檔重跑。 【在哪裡能用】Google AI Pro 與 Ultra 方案，Antigravity App 與 Antigravity CLI 都能用；App 內建 Python，不必另裝（可用 ANTIGRAVITY_PYTHON 指定自己的 Python 3.8+）。 【限制】每支腳本執行前預設要你核准（除非權限預設已允許）；子代理各自依權限設定在自己的對話裡請求核准。同版還有 Everforest 主題、提示詞跳轉快捷鍵與內建瀏覽器防護等 11 項改進、13 項修正，官方說逐步推出。

來源：Antigravity 官方 Changelog ↗官方文件：Dynamic Workflows ↗EmpireX 整理 ↗

Grok Bot 教學與實用資訊

1 則：Grok Bot 團隊工程師分享怎麼讓 AI 代理大量寫碼又不出錯。

  1. 2026-11-15

    Grok Bot 團隊怎麼信任 AI 寫的碼

    學到：不要逐行審 AI 的程式，而是先把架構規則、lint、自動測試與執行期驗證做好，讓代理自己證明沒寫壞；作者說團隊一個月合併約 11,000 個 PR、回滾率約 0.5%。

    回滾率（Revert rate）：合併後又被撤回的程式變更比例，越低代表品質越穩形式驗證：用數學方法證明程式在所有情況下都符合規格，而不只是測幾個案例

    看更多

    AI Engineer 頻道（台北 11/15 上傳，約 17.5 分鐘）。依影片說明欄與章節：講者 Lauren Tan（poteto）說明 Grok Bot 團隊如何用軟體架構、lint 規則、自動測試、執行期驗證，以及 TLA+、Lean 形式驗證來放大 AI 寫碼代理，並搭配 Cursor agents 與 pstack 外掛建立「軟體工廠」。章節包括：信任金字塔與程式碼品質、用 lint 規則取代註解、把 token 花在驗證上、11,000 個 PR 與 0.5% 回滾率、先打地基再談軟體工廠。數字為講者自述。

入門 · VRAM 官方頁未列顯存需求；範例用 SD1.5 系模型與 control_v11p_sd15_scribble_fp16，依原頁為準常青教學

ComfyUI ControlNet 入門：用一張塗鴉草圖控制生成構圖

學會把 ControlNet 模型放對資料夾，載入官方範例，讓 AI 照你的草圖構圖去畫，而不是一直重抽。

ControlNet：給生圖模型額外條件（線稿、深度圖、骨架）的外掛模型，讓構圖可控

看更多：步驟
  1. 到官方頁下載工作流圖片，直接拖進 ComfyUI 載入（圖片裡含工作流與模型下載連結）。
  2. 若自動下載失敗，手動下載 dreamCreationVirtual3DECommerce_v10、vae-ft-mse-840000-ema-pruned、control_v11p_sd15_scribble_fp16，分別放進 models/checkpoints、models/vae、models/controlnet。
  3. 下載官方提供的塗鴉輸入圖，在 Load Image 上傳，按 Queue 生成。
  4. 其他類型（線稿、深度、姿勢）流程相同：換對應的 ControlNet 模型並上傳對應參考圖；核心節點不含全部前處理器，需要時裝 ComfyUI ControlNet aux。
教學來源：ComfyUI 官方：ControlNet 教學 ↗ComfyUI ControlNet aux（前處理器節點） ↗
中階 · VRAM 官方安裝頁未列顯存需求，依要跑的模型而定常青教學

手動安裝 ComfyUI（Windows／macOS／Linux）：虛擬環境＋原始碼＋GPU 套件

學會不用安裝程式、自己用 Conda 與 Git 裝 ComfyUI，之後更新與除錯更好掌握。

虛擬環境：替單一程式準備的獨立 Python 環境，裝套件不會弄亂系統或其他程式

看更多：步驟
  1. 安裝 Miniconda，建立並啟用環境：conda create -n comfyenv、conda activate comfyenv。
  2. 確認已裝 Git，執行 git clone https://github.com/Comfy-Org/ComfyUI.git（Windows 另需 Visual C++ Redistributable）。
  3. 依顯卡裝 PyTorch：NVIDIA 用官方頁的 cu130 指令；AMD、Apple Silicon、Intel Arc 各有對應指令，照原頁複製。
  4. 進 ComfyUI 資料夾安裝相依套件並啟動（指令照官方頁）；也可改用 ComfyUI CLI 安裝與管理。
教學來源：ComfyUI 官方：手動安裝 ↗ComfyUI GitHub ↗
