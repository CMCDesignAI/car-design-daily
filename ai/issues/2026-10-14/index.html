Gemini 4 Argon is now available for everyone

昨天還只給少數資安夥伴試用的 Gemini 4 Argon，Google 10/13 宣布全球開放。【在哪能用】Gemini App 與 Google 搜尋 AI 模式：Google AI Pro 與 Ultra 訂戶；開發者：Gemini API 付費層（AI Studio、Android Studio）；Antigravity 寫程式平台限 Ultra。免費方案與 Pro 方案的 API 額度都不能用（官方文件）。【價格】API 到 11/30 前為限時價：每百萬 token 輸入 2、輸出 10 美元（快取輸入打 95 折扣至 0.10）；12/1 起變成 4／20 美元，和 Claude Opus 5.5 同級。【比上一代進步在哪（官方說法）】回答更直接、少廢話與套話，長任務會更常回報進度；寫程式大幅進步，官方稱在 Vals Index 排第一，Chrome 團隊用它重構大型程式碼。它也是目前 LMArena 文字榜第一（Preliminary）。Ars Technica 另提到 Google 近期已把免費用戶的 Flash 模型收回、只剩 Flash-Lite。【實測】以下為 YouTube 創作者的上手實測影片，屬初步、樣本小。

用 FreeVideo 在自己電腦跑 MiniMax H3 影片

學會安裝 FreeVideo，生成第一支 H3 影片，並用新的剪輯畫面把影片接長。

ComfyUI：用拖拉「節點」組合 AI 生圖／影片流程的免費軟體VRAM：顯示卡記憶體，決定能跑多大的模型

看更多：步驟
  1. 到 GitHub Releases 下載 FreeVideo（Windows 為 FreeVideo.exe，需 NVIDIA 顯卡）。
  2. 執行後選擇既有的 ComfyUI 資料夾或安裝新的，按「Install & launch」。
  3. 在創作面板輸入描述，生成第一支短片。
  4. 要更長：到剪輯畫面把片尾往後拉出新段落，打開「首幀參考」後按生成。

只改圖的一小塊：ComfyUI 局部重繪（Inpaint）

學會用遮罩只重畫不滿意的地方，例如手、衣服或多餘物件，其他部分不動。

Inpaint（局部重繪）：只重新生成圖中被遮住的區域遮罩（Mask）：標出「要改哪裡」的範圍

看更多：步驟
  1. 下載官方範例的 512-inpainting-ema.safetensors，放進 ComfyUI/models/checkpoints。
  2. 把官方範例流程圖拖進 ComfyUI，載入範例輸入圖（已含遮罩）。
  3. 按 Queue（或 Ctrl+Enter）生成，不滿意就換 KSampler 的種子重試。
  4. 改自己的圖時，用遮罩編輯器（Mask Editor）塗出要改的區域。
