Step 5 Preview: StepFun's flagship model for agentic work — 600B total parameters, 27B active, up to 1M context

中國 AI 公司階躍星辰（StepFun）的旗艦模型 Step 5 Preview 以開放權重形式放上 Hugging Face 與 ModelScope（FP8、BF16，另有 NVFP4 版），10/18 起多家媒體報導。官方模型卡寫明：600B 總參數、每個 token 只啟用 27B，上下文最長 100 萬 token，可輸入文字、圖片和影片，主打寫程式、長時間的代理任務與專業文件分析，特別強調金融。【成績】依官方自測表，DeepSWE v1.1 67.7、ProgramBench 80.5、FrontierFinance 66.4；在多數項目贏過 Kimi K3、GLM-5.3，但 Terminal-Bench v4 只有 33.3，明顯落後 GPT-6 Astra（57.9）與 Claude Opus 5（52.3），以上皆為廠商數字。【限制】授權是 StepFun Model License 1.0（類 Apache 2.0，但有署名與商用條件），正式上線前要讀授權；完整權重仍需要資料中心等級的 GPU，一般電腦跑不動。【哪裡能用】下載權重用 vLLM／SGLang 自架，或用階躍星辰 API 平台。

NVIDIA RTX Spark PCs Available Today — A New Beginning for Windows PCs

NVIDIA 10/16 宣布 RTX Spark 筆電開賣，首波來自 ASUS、Dell、HP、Lenovo、Microsoft 與 MSI。它把 Blackwell RTX 顯示晶片和 Grace CPU 做成一顆超級晶片，CPU 和 GPU 共用最高 128GB 記憶體，官方說 AI 算力最高 1 petaflop（FP4）。【能做什麼】官方強調可在本地同時跑大型語言模型、AI 代理與創作軟體，首發就支援 Photoshop、Premiere、Hermes、OpenClaw 等代理，並提供免指令列的安裝引導；NVIDIA 自家的 Nemotron 3.5 Bolt 74B 也能在支援的機型上跑。【價格】媒體報導起價 2,399 美元，但 128GB 是最高配置，起價機型不含；Tom's Hardware 列出的部分機型預購價從 2,599 美元起，各款以廠商公告為準。

MOSS-Image: a 5B open-weights text-to-image model with layout-guided generation

復旦 OpenMOSS 團隊開源 MOSS-Image，是 5B 參數的單流 DiT 文生圖模型，授權 Apache 2.0（可商用）。【特色】可以讀一份 JSON 排版：畫框指定每個物件和每行文字放哪裡，模型照著擺；能畫出清楚的中英文字，提示詞可長到約 4K token。分 SFT（一般使用、排版較乾淨）和 Base（給人做 LoRA 微調）兩個版本。【在哪裡用】ComfyUI 當天就原生支援，並附「畫框排版」節點與 4 個範本，官方範本需要 ComfyUI 0.41.3 以上；Comfy-Org 重新打包的 INT8 檔約 5.4GB、BF16 約 10.2GB（依 kombitz 整理）。【限制】官方建議 50 步以上、CFG 3，速度不算快；品質說法來自官方與早期整理，尚無大量實測。

入門 · VRAM 官方未標示；範本預設載入 INT8 檔，BF16 版要更多顯存（依原頁為準）本週新教學

在 ComfyUI 跑 MOSS-Image：文生圖與畫框排版

用官方範本跑 MOSS-Image，並用畫框指定物件和文字的位置。

範本（Template）：ComfyUI 內建、別人已經接好的工作流程，打開就能用Bounding Box：在畫面上拉出的方框，用來告訴模型東西要放哪裡

看更多：步驟
  1. 先把 ComfyUI 更新到 0.41.3 以上（官方範本的版本需求）。
  2. 在 Template 搜尋 MOSS-Image，選「MOSS-Image: Text to Image」。
  3. 照官方頁的模型清單，從 Hugging Face 的 Comfy-Org/MOSS-Image 下載檔案放到對應資料夾。
  4. 輸入一句想法按 Queue；範本內建提示詞擴寫，會自動補成完整描述。
  5. 要指定位置時改選 Layout-Guided 範本，在 Create Bounding Boxes 拉框並替每個框寫說明，文字框會直接畫出框裡的字。
教學來源：ComfyUI 官方：MOSS-Image 教學 ↗Hugging Face：Comfy-Org/MOSS-Image 模型檔 ↗

安全更新 ComfyUI：可攜版、桌面版、手動安裝各怎麼升級

依自己的安裝方式把 ComfyUI 升到新版，跑得動新模型的範本，又不弄壞原本的環境。

Stable／開發版：Stable 是測過的穩定版；開發版最新但比較可能有 bug虛擬環境：專門給 ComfyUI 用的獨立 Python 空間，避免和電腦裡其他程式互相干擾

看更多：步驟
  1. 先確認自己是可攜版（Portable）、桌面版（Desktop）還是手動安裝。
  2. 可攜版：到 update 資料夾執行 update_comfyui.bat（想要穩定版就用 update_comfyui_stable.bat）；官方警告除非要修相依套件，否則不要用會重裝全部套件的那支。
  3. 桌面版：打開 Manage 面板的 Update 分頁，選 Stable 或 Latest on GitHub 頻道更新。
  4. 手動安裝：先啟用虛擬環境，在 ComfyUI 資料夾執行 git pull，再跑 pip install -r requirements.txt，最後重新啟動。
  5. 更新前先備份整個資料夾；更新後若出現節點缺失，照官方頁的常見問題排查。
教學來源：ComfyUI 官方：How to Update ComfyUI ↗
