Mistral Large 4 開放下載

歐洲 Mistral 的旗艦大模型開放權重，企業可以自己架設，API 價格也比同級閉源模型便宜。

開放權重（Open weights）：公開模型檔案讓人下載、自己架設，但授權條件不一定等於完全開源MoE（混合專家）：模型很大，但每次只叫出一部分參數運算，所以速度和成本比總參數看起來低

看更多

Mistral Large 4 weights are now available under the Mistral Ecosystem Open-Weight License.

【新內容】10/08 報過預覽版；10/29 Mistral 把正式版權重放上 Hugging Face。【規格】總參數約 1 兆、每次只啟用約 49B（含嵌入與輸出層約 52B），上下文 100 萬 token，可輸入文字和圖片、輸出文字，支援 160 多種語言；另有 FP8 和給 NVIDIA Blackwell 用的 NVFP4 版本，社群已有 Unsloth／llama.cpp 的 GGUF。第一天就支援 transformers、vLLM、llama.cpp、SGLang。【價格】API 每百萬 token 輸入 0.70 美元、快取輸入 0.07 美元、輸出 2.10 美元；也能在 Mistral Studio、OpenRouter、NVIDIA NIM 使用。【限制】授權是修改過的 MIT，一般自用、商用可以，但把它包成模型 API 服務賣給別人要另外簽商業授權；模型體積很大，個人電腦跑不動完整版。TechCrunch 說它主打資安任務，表現和 GLM-5.3 相近、每個任務少用 47% token（廠商說法）。

松音的 H3 Colab 玩具箱

松音把 MiniMax H3 包成像玩具一樣的介面放上 Colab，不用設定 ComfyUI，在雲端點幾下就能做影片。

  • 在 Colab 筆記本裡一個個欄位點完、按個鍵就開始，ComfyUI 什麼都不用設定；要搬到自己電腦也容易。
  • 用「@」標記參考音和參考圖，做法跟 EasyH3 相同；提示詞改寫可用 Gemini，或用他自己量化的 9B（w4a8）小模型在本地跑。
  • 他的實測：文戲 480P、8 步很快就能出片、成本低；動作戲表現比較普通但堪用。內建延伸功能，從素材庫拖影片進來就能接著往下生成。
  • 程式放在 GitHub 的 dseditor/minimax-h3-colab，裡面另有基本版和會說話的數位人筆記本。

T8star-Aix · YouTube2026-10-30

T8 開源 Drama-3 語音導演台

T8 把 Fish Audio 的 Drama-3 配音模型做成本地「語音導演台」和 ComfyUI 節點，可以分角色配音、挑選和修改台詞。

  • 專案 Comfyui-Drama-3（GPL-3.0）有本地工作室和 30 個 ComfyUI 原生節點、19 個工作流；Windows 整合包內含 Python 環境，執行 Start-Drama3.exe 就能開。
  • 流程是先建角色聲音庫（上傳乾淨的參考音即可，不用訓練），再匯入台詞或 SRT 生成多個版本比較、鎖定滿意的，最後匯出 WAV、分軌和字幕。
  • 可以只重錄一句裡的一小段（infill），也能用導演指示改情緒和語速；作者提醒情緒和語速是模型控制，不保證精準時間。
  • README 說完整模型需要不少 RAM／VRAM，沒有給具體數字；影片裡的回音是錄影時外放造成，不是專案問題。

Infill（局部重錄）：只重新生成音檔中選定的一小段，前後保持不變

Pose ControlNet：用骨架圖控制人物姿勢，再兩段生成補細節

學會用 OpenPose 骨架圖指定人物的動作和站姿，再用第二個模型重畫一次，讓大圖的臉和細節更清楚。

OpenPose：CMU 開發的姿勢偵測，把人轉成頭、肩、手肘、膝蓋等關鍵點連成的骨架圖兩段生成（2-Pass）：先生成一張姿勢正確的底圖，再用另一個模型在這張圖上重畫、補細節

看更多：步驟
  1. 把官方頁面上的工作流程圖片拖進 ComfyUI，會載入整個流程並提示下載模型。
  2. 若自動下載失敗，手動下載 control_v11p_sd15_openpose_fp16.safetensors 放進 models/controlnet/，majicmixRealistic_v7 和 japaneseStyleRealistic_v20 放進 models/checkpoints/，vae-ft-mse-840000-ema-pruned 放進 models/vae/。
  3. 在 Load Image 上傳官方提供的骨架圖（或你自己的 OpenPose 圖），確認兩個 Load Checkpoint 分別選到兩個模型。
  4. 按 Queue（或 Ctrl+Enter）生成：第一段先定姿勢，第二段放大重畫補細節。
教學來源：ComfyUI 官方文件：Pose ControlNet 兩段生成 ↗Hugging Face：ControlNet v1.1 fp16 模型 ↗
入門 · VRAM 官方文件未標示，依原頁為準常青教學

SAM 3.1：打一個詞就把影片裡的物體自動摳出來

學會在 ComfyUI 用 Meta 的 SAM 3.1，輸入「car」這類文字就能在圖片或整段影片裡分割、追蹤目標，做成遮罩給後續合成或重繪用。

分割（Segmentation）：把畫面中某個物體的範圍精準圈出來，產生只包含它的遮罩遮罩（Mask）：黑白圖，白色是要處理的區域、黑色是不動的區域

看更多：步驟
  1. 先把 ComfyUI 更新到最新版（範本庫找不到 SAM3 通常代表版本太舊）。
  2. 打開 Workflow → Browse Templates，在 Utility 分類找到「SAM3: Video Segmentation」或「SAM3: Image Segmentation」載入。
  3. 在 LoadVideo（或 Load Image）節點放入素材，提示詞用簡短英文寫要摳的東西，多個目標用逗號分開（上限 32 個 token）。
  4. 按 Run，輸出就是每一格都套好遮罩的結果；模型授權是 Meta 的 SAM License，商用前先看條款。
