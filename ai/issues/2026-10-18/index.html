DeepSeek-V4.1-Flash-1017

DeepSeek 10/17 把網站、App 與 API 上的 Flash 模型更新為 V4.1-Flash-1017（API 名稱 deepseek-flash 直接指向新版，舊名 deepseek-v4-flash 仍可呼叫但會轉給新版），權重同步放上 Hugging Face。【比上一版進步在哪】官方模型卡稱這是小改版，但推理、寫程式、代理任務與視覺測試都明顯提升，而且做事更快、輸出更短、成本更低；例如 DeepSWE v1.1 從 74.2 升到 77.0、Automation-Bench 從 54.8 升到 60.5（官方自測）。官方表格中 Opus 5 在 Terminal-Bench 4.0 與 HLE 仍領先。【其他】同時對所有人開放 Search／Fetch API（用自家搜尋引擎），每 1,000 次成功呼叫 0.75 美元（Yahoo／Investing.com 報導）。獨立評測尚未出爐。

Welcome Beam: a 501B open model you can own, customize, and scale

美國新實驗室 Reflection 10/16 把首個模型 Beam 的權重放上 Hugging Face（之前只預告「10 月稍後開源」，這次是實際釋出）。Beam 是混合專家（MoE）架構，總參數 501B、每個 token 啟用 23B，只吃文字、上下文 1M token，採寬鬆的 Apache 2.0 授權，可商用。提供 BF16、FP8、NVFP4 版本，並附自家開源的 Rust 程式代理工具。【硬體】Hugging Face 說明 BF16 約 1TB，NVFP4 約 280GB，建議 4 張 B200 或 8 張 RTX Pro 6000 等級，不是一般家用電腦能跑；沒有這類硬體可改用推論服務。【在哪能用】Transformers、vLLM、SGLang 首日支援，並已上 Hugging Face 推論服務等平台。

FLUX 3 Image Klein: open weights, 5.6B parameters

Black Forest Labs 10/15 釋出 FLUX 3 Image Klein 權重，一個模型包辦文生圖、改圖與最多 10 張參考圖生成，支援原生 4K 與框選區域控制。【比上一版進步在哪】官方內部評測稱比 FLUX.2 [klein] 9B 在文生圖高 91 Elo、改圖高 70 Elo，參數卻少 38%；也稱在同場比較中領先 Qwen-Image 2.1（7B）與 Krea 2（12.9B）。【硬體】生成器權重 BF16 約 11.2GB、FP8 約 5.6GB；INT8 版可在 8GB 顯存的 RTX 顯卡上透過 ComfyUI 或 Diffusers 跑，RTX 4070 生成一張 1MP 圖約 9 秒內（NVIDIA 實測、蒸餾版 16 步）。【授權與價格】FLUX Kommunity License，年營收 500 萬美元以下可免費商用；API 每張 1K 圖 0.009 美元起。ComfyUI 首日支援（需 0.41.0 以上）。

入門 · VRAM 官方稱 INT8 版最低 8GB（RTX 3070 等級）；顯存超過 24GB 可換 BF16 版本週新教學

在 ComfyUI 跑 FLUX 3 Image Klein：文生圖與改圖

用官方範本在自己的顯卡跑 FLUX 3 Klein，知道完整版和蒸餾版該怎麼選。

範本（Template）：ComfyUI 內建、別人接好節點的工作流程，載入就能用提示詞擴寫（Prompt upsampler）：先用另一個語言模型把你的短提示寫成完整描述，再拿去生圖

看更多：步驟
  1. 把 ComfyUI 更新到 0.41.0 以上（舊版找不到 FLUX 3 Klein 範本）。
  2. 在範本庫搜尋「FLUX 3 Image Klein Distilled: Text to Image」載入，依提示下載 INT8 版模型檔。
  3. 輸入提示詞；蒸餾版用 4–16 步（預設 16）、不需要 guidance，按 Queue 生成，圖會存到 ComfyUI/output/。
  4. 想改圖就換成 Image Edit 範本，放入參考圖並用一句指令說要改什麼。
  5. 提示詞擴寫預設開啟；想完全照自己的字生圖，就關掉 enable_prompt_upsampler。
教學來源：ComfyUI 官方：FLUX 3 Image Klein 教學 ↗GitHub：flux-3-image-klein 參考程式 ↗
入門 · VRAM 依所用主模型而定（範例用 SD1.5，依原頁為準）常青教學

ComfyUI 同時套用多個 LoRA：串接節點混出新風格

把兩個以上的 LoRA 串起來用，並用強度數值調整各自的影響。

LoRA：小小的附加模型檔，能在不換主模型的情況下加入特定畫風或角色strength_model：LoRA 的強度，數字越大影響越明顯

看更多：步驟
  1. 照官方頁下載主模型與兩個範例 LoRA，分別放進 models/checkpoints 與 models/loras。
  2. 載入官方範例工作流程，確認兩個 Load LoRA 節點是一個接一個串起來的。
  3. 在兩個 Load LoRA 節點分別選好 LoRA 檔，按 Queue 生成。
  4. 調整兩個節點的 strength_model，比較不同比例混出的風格差異。
